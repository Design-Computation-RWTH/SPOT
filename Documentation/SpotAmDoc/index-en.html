Ontology Specification Draft

Abstract

The SPOT Axis Mapping (SPOT-AM) Ontology is an extension of the Space Types Ontology (SPOT) that enables precise definition of spatial transformations between spaces through axis and boundary point mappings.

By decomposing transformations into rotation and translation components, SPOT-AM supports both automated and manual creation of spatial metadata, accommodating varying levels of accuracy and human readability.

Introduction back to ToC

While the core Space Types Ontology provides a framework for spatial data organization, a more detailed mechanism is needed to define the precise positioning and orientation of spatial relationships between spaces.

The SPOT Axis Mapping (SPOT-AM) Ontology addresses this by enabling the definition of spatial transformations through two complementary mechanisms: Axis Mappings, which define the rotational relationship between spaces, and Boundary Point Mappings, which define their translational positioning. Both support varying levels of accuracy and can express spatial relationships either quantitatively through normalized coordinates or qualitatively through human-readable directional relations via the Relative Location Ontology (RELOC).

Axis Mappingc back to ToC or Class ToC

IRI: https://w3id.org/spot/am#AxisMapping

The Axis Mapping is related to an Appearance of an Entity Space and defines which Axis of the Entity Space (Source Axis) can be mapped to which Axis of the Reference Space (another Entity, Document or Asset Space). This relation can be further specified with an angle and accuracy. An AxisMapping object can only relate on Source Axis to one Reference Axis. Thus, typically, each Entity Space Appearance links to three Axis Mapping objects.

has accuracy op, has axis relation type op, has source axis op, has source to target angle dp, has target axis op

Boundary Point Mappingc back to ToC or Class ToC

IRI: https://w3id.org/spot/am#BoundaryPointMapping

The Boundary Point Mapping describes the relation of an Entity Axis Boundary Point (Source Point) to the reference space. The relation can be expressed by Directional Properties of the RELOC Ontology (e.g., containedInFront/Right/Bottom etc.) and/or as a Normalized Coordinate in relation to the reference space. If both properties are given the the normalized coordinate is to be interpreted in the context of the area defined by the RELOC Property (e.g., Point <reloc:containedInRight> RefSpace. --> '0.5' describes the center of the Right Area of the Reference Space)
